# Professor 0.12.0-beta.1 — Mac Beta

Date: 2026-10-15. This is the first prepared Beta source snapshot, not a stable or fully
cross-platform release. It is intended for evaluation on Apple Silicon Mac with DeepSeek Harness.

## Included

- Professor Home, course/material organization, persistent learning context and saved notes/reviews.
- 22 Professor tools, six bundled skills and five learning presets.
- Deeper explanations with definitions, justified steps, worked examples and knowledge connections;
  explicit brief/hint/formula-sheet requests retain their scope.
- Local PDF text/image reading and optional local OCR/structure enhancement on the material-read
  path. The indexing extraction path does not OCR scanned documents.
- A bundled CSC3001-derived LaTeX default shared by all learning presets, with large headings,
  semantic colored boxes, math, tables, listings and diagrams. Usable custom templates win.
- One-pass LaTeX `body_tex` sections/examples/review derivations; ordinary prose remains escaped.
- Session sandbox-policy propagation, bounded structural preflight and actionable compiler errors.
- Creation/preflight/compile timing, precise partial visual coverage, and in-memory compile reuse
  for unchanged, fully fingerprinted sources and PDF bytes. Uncertain dependencies disable reuse.

## Installation and requirements

Install the plugin using the bundle/profile instructions in the repository README. Source users
can install/link this snapshot; tarball users must use the matching Beta archive. Reload the
plugin and start a fresh Professor session after updating. Saved teaching preferences are retained;
reapply the progressive preset if the updated teaching defaults are desired.

Node.js 20 or newer is required by the package. Harness is the host application. OCR enhancement
setup needs Python 3.12 and initial dependency/model downloads; recognition then runs locally.
LaTeX PDF generation needs a local TeX distribution, XeLaTeX, Fandol fonts and the packages listed
in `resources/latex/README.md`. These runtimes are not embedded in the plugin tarball.

## Validation and limits

Before Beta metadata preparation, the complete local verification passed 893 tests, zero failures
and zero skips with the existing enhancement runtime configured. The packed copy passed 66
LaTeX-focused tests. A synthetic two-page document was created with the real artifact API,
compiled with local XeLaTeX, rendered with PDFium, and both pages inspected. Its inspection-only
record reused the verified PDF without a third compiler call. These are local engineering
observations, not native model-delivery or end-to-end latency guarantees. Release preparation
reruns validation on the exported snapshot and records exact results with the release artifacts.

Known limitations:

- Real Windows/Linux and Mac Intel host acceptance is not complete.
- The original user-session sandbox write denial has not been replayed in the same session.
- Native model automatic skill use and complete source-grounded LaTeX delivery have outstanding
  acceptance work; deterministic and supplied-skill examples do not substitute for it.
- The historical teaching-model matrix was 6/8. The other two cases were accepted as retained
  limitations, not relabelled passing. Home visual/native launched-model acceptance is incomplete.
- Archive/hide is supported where the host provides it; permanent native chat deletion is not.
- OCR and page-image availability do not guarantee every source table/diagram was read. Missing
  source evidence must remain disclosed. Compilation does not establish mathematical correctness.
- Structural TeX preflight is deliberately bounded, not a complete parser. Visual review reports
  the pages actually inspected, and uncertain dependency cases may require a fresh compile.

## Publication and licensing

dependencies and the original private Git history. Preserve the development repository separately.

sample identity; generated default notes use current course metadata instead of that identity.

has been selected in this snapshot. The owner selected the private GitHub repository `undefinedfrancis/dsh-professor-plugin`
for this Beta. Do not describe this Beta as an open-source release until the license
