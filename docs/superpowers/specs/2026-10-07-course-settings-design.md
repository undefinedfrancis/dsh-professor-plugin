# Phase 6 — lightweight Course and Settings

User approved the lightweight plan in chat on 2026-10-07. Preserve existing Home and native
conversation routing. Add course details/material categories/recent-session entry points and
settings for folder confirmation, course configuration, skill preferences, memory, indexing/health.
No dashboards, custom PDF viewer, new registry, source reorganization or transcript storage.

Read views use the connected authoritative project and files index through the existing fs gateway.
Stable course/file IDs are resolved server-side. Unknown courses, missing indexes, unsupported
schemas and unavailable storage are explicit states, not fabricated empty successes. Paginate/bound
results; never accept arbitrary material paths from the browser. Revalidate files before launch.

Mutations reuse existing onboarding/config/index/memory/customization contracts. Course IDs remain
immutable; folder ambiguities require user confirmation. Settings save uses revision/version guards.
Do not create a new preset service requiring isolate realms. Extend the existing authenticated
professorHome bridge with strict inputs. Model turns never start automatically.

Use the current host React and scoped keyed panel. Components hold navigation/form state only;
backend services own policy and academic behavior. Clear labels, keyboard operation, explicit
pending/success/error/retry states, duplicate-submission prevention and no inactive fake buttons.
Disable withdraws all contributions. Memory disabling retains records; rebuilding touches derived
indexes, not memory or original materials. Native plugin enable/disable remains a host-owned action.

Test service failures, invalid selectors, courses switching, reset and memory toggling before UI.
Then verify a packed disposable real browser: connect/confirm courses, inspect materials, customize,
launch native study, rebuild and inspect health without editing YAML. Compare source and real-profile
fingerprints. Model teaching and whole-project release are separate Phase 7–8 gates.
